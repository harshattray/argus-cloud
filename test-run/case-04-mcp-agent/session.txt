2. tools/list — what an agent sees
================================================================

- list_frames
  List the frames Normascope tracks in this project: label, screenshot name, mode (fidelity/baseline), design source, and whether a capture exists yet.
  input: []

- capture
  Capture screenshots of the running app for the configured frames (their routes/selectors). Origin policy is default-deny: only configured origins can be captured; private/link-local/metadata addresses are always refused.
  input: ["url"]

- compare
  Run the visual comparison and return the structured summary. Two modes: with no arguments, compares the configured frames (fidelity/baseline per config). With `target` (a mock PNG path inside the project) and `url`, runs the zero-config target-mock flow: capture the URL, diff against the mock. The aligned mismatch percent is the primary score; lower is better.
  input: ["target","url","selector","width","height"]

- get_summary
  Return the structured summary of the most recent comparison (summary.json v2: per-frame aligned mismatch %, SSIM, drifted sections, mode, source, flagged).
  input: []

- explain
  Explain WHY flagged frames drifted, as structured findings (hypotheses — verify before applying; nothing is auto-applied). Two modes: BYO — with ANTHROPIC_API_KEY in the server env, analysis runs locally against your own key. Org credits — with NORMASCOPE_CLOUD_URL + NORMASCOPE_ORG_KEY set, the current summary is uploaded to Normascope Cloud and analyzed there (metered in credits; findings gain history context). Deterministic diff scores are never affected by this tool.
  input: ["frame","deep"]
